# 安全与脱敏

## 公开版本做了什么

- **移除 SQL**：`前台/后台页面/index.php` 里读取 `admin_settings` 的闭包被替换为静态默认值，仓库不含任何 SQL 语句。
- **后端路径**：全部改为 `_backend.php` + `JIYAN_BACKEND_ROOT`，不暴露服务器目录。
- **管理接口**：`公告中心.js`、`公告弹窗.js` 中的管理接口地址改为 `/api/console/api.php` 占位。
- **占位串**：签名占位、下载地址均为示例值，不是生产值。
- **凭据**：仓库不含数据库账号密码、SMTP 凭据、签名私钥、服务器 IP。

## 部署者需要做的

1. 映射 `/api/console/api.php` 到自己的后端接口。
2. 修改 `YOUR_SIGNATURE_SALT` 为你自己的值，并与后端保持一致。
3. 替换下载地址为你的真实地址。
4. 不要把私有后端的 `config.php`、密钥文件放进 Web 根目录。

## 报告问题
