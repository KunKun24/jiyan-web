# 常见问题

**为什么仓库里没有管理后台？**
本项目只开源用户端。管理后台、服务端、数据库与签名密钥不在开源范围，也不接受相关 PR。

**可以部署到自己的域名吗？**
可以，但必须与 API 同源（同域名或同站反向代理）。登录态与云控面板会话都是 HttpOnly Cookie，跨站不会携带。

**能部署到 GitHub Pages 吗？**
静态页面能打开，但接口会因跨域/缺少 Cookie 而失败。若坚持使用，需要自建同源反代，前端代码不需要改。

**ENV 传输是加密吗？**
不是。它只是逐字节编码，用于兼容旧协议；安全性来自 HTTPS 与服务端会话。

**卡密解绑有什么风险？**
解绑会清除设备绑定，并可能扣减解绑次数或时长，具体取决于应用配置。请只在确认真实需要时操作。

**查询提示「查询过于频繁」？**
公开工具按 IP 限流（每分钟 20 次、每天 300 次），等待后再试，或更换网络环境。

**为什么云控面板提示「请开通会员」？**
云控是会员能力，需账号具备有效会员且拥有该应用。

**可以商用或二次开发吗？**
可以，遵循 AGPL-3.0；若作为网络服务对外提供修改版，需要公开对应源码。名称与 Logo 不在授权范围内。
